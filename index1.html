Conseils post-simulation
Si le temps < 1 an
Le mot de passe est vulnerable a une attaque brute force avec un budget moyen. Passez a 16+ caracteres avec un pool mixte.
Si le temps < 1 siecle
Resistant aux attaques classiques mais pas aux acteurs etatiques. Utilisez une passphrase de 5+ mots ou activez la 2FA.
Si le temps < 1 seconde
Mot de passe compromis immediatement. Changez-le immediatement et n'utilisez jamais ce pattern ailleurs.

Recommandation par profil
Utilisateur grand public
Adoptez les passkeys des que possible (iCloud Keychain, Google Password Manager). En attendant, utilisez un gestionnaire de mots de passe + TOTP.
Professionnel / Entreprise
Deployez les passkeys pour l'authentification primaire. Gardez les cles physiques FIDO2 comme fallback. Eliminez progressivement les SMS 2FA.
Journaliste / Activiste / Cible haute valeur
